# ЛР №1 (BigTech): классы и инкапсуляция. Вариант 5 - «Авиарейс и расписание»

Консольное приложение на Java. Демонстрирует инкапсуляцию: классы сами защищают
инварианты предметной области, а объект нельзя привести в некорректное состояние извне.

## Классы

| Класс      | Роль                                                                 |
|------------|----------------------------------------------------------------------|
| `Route`    | Неизменяемый класс-значение: пункт вылета и назначения (не совпадают)|
| `Flight`   | Сущность: номер, маршрут, всего мест, продано мест                   |
| `Schedule` | Контейнер рейсов с закрытым массивом                                 |
| `Main`     | Демонстрация: корректные операции и намеренные нарушения правил      |
